# Cau 5: So sanh IC 74LS125 va 74LS126

Ca hai la bo dem 3-trang thai (0, 1, Z). Khac biet duy nhat la muc logic cua chan enable:

| Dac diem | 74LS125 | 74LS126 |
|---|---|---|
| Chuc nang | Quad bus buffer 3-state | Quad bus buffer 3-state |
| Enable | **Active-LOW** (enable=0 -> output active) | **Active-HIGH** (enable=1 -> output active) |
| Khi enable khong active | Output high-impedance (Z) | Output high-impedance (Z) |
| Ky hieu enable | Co bubble (cham tron) | Khong co bubble |

- 74LS125: output kich hoat khi enable = 0; enable = 1 -> Z.
- 74LS126: output kich hoat khi enable = 1; enable = 0 -> Z.
