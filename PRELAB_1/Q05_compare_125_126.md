# Câu 5: So sánh IC 74LS125 và 74LS126

Cả hai là bộ đệm 3-trạng thái (0, 1, Z). Khác biệt duy nhất là mức logic của chân enable:

| Đặc điểm | 74LS125 | 74LS126 |
|---|---|---|
| Chức năng | Quad bus buffer 3-state | Quad bus buffer 3-state |
| Enable | **Active-LOW** (enable=0 -> output active) | **Active-HIGH** (enable=1 -> output active) |
| Khi enable không active | Output high-impedance (Z) | Output high-impedance (Z) |
| Ký hiệu enable | Có bubble (chấm tròn) | Không có bubble |

- 74LS125: output kích hoạt khi enable = 0; enable = 1 -> Z.
- 74LS126: output kích hoạt khi enable = 1; enable = 0 -> Z.

Z không đồng nghĩa logic 0. Trạng thái này ngắt tác động chủ động của output để có thể chia sẻ bus.
