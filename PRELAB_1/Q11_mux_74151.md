# Cau 11: f(x,y,z) = Sigma(2,3,5,7) dung 74LS151

**Phan tich:**
f = m2 + m3 + m5 + m7
(z la LSB)
- m2: 010 -> xbar.y.zbar
- m3: 011 -> xbar.y.z
- m5: 101 -> x.ybar.z
- m7: 111 -> x.y.z

**Dung 74LS151 (8-to-1 MUX):**
- Chon A2 = x, A1 = y, A0 = z.
- Dau vao du lieu D0-D7:
  - D0 = 0, D1 = 0, D2 = 1, D3 = 1
  - D4 = 0, D5 = 1, D6 = 0, D7 = 1
- Noi D2, D3, D5, D7 len VCC (1); D0, D1, D4, D6 xuong GND (0).
- Chan Strobe Sbar (chan 7) noi GND (enable).
- Output Y (chan 5) = f.

**IC can dung:** 1 x 74LS151 + co the 74LS04 neu can dao tin hieu chon.
