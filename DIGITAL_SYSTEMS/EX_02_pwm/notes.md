# EX_02 — PWM Generator

## Khái niệm
PWM (Pulse Width Modulation): điều khiển độ rộng xung để điều khiển công suất.
- duty = 0% → output luôn 0.
- duty = 50% → output HIGH 50% thời gian.
- duty = 100% → output luôn 1.

## Ứng dụng
- Điều khiển tốc độ động cơ.
- Điều khiển độ sáng LED.

- Audio amplification (Class D).
